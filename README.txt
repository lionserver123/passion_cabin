# 熱情管理小屋｜網路發佈版

## 這個版本有什麼
- 手機與電腦都能開啟的單頁網頁
- 可加入手機主畫面，像 App 一樣開啟（需透過 HTTPS 網站）
- 支援載入後的基本離線開啟
- 興趣與紀錄仍存在目前瀏覽器的 localStorage
- 網頁內可匯出／匯入 JSON 備份

## 重要：資料保存方式
這個版本沒有雲端帳號或資料庫。即使網站已公開上網，每台裝置／每個瀏覽器的紀錄仍是分開的；清除瀏覽資料也可能刪掉紀錄。請定期使用「資料備份」匯出 JSON。
如果你希望 iPhone、iPad、電腦之間自動同步，需要再加上登入與雲端資料庫。

## 最簡單的發佈方式（Netlify Drop）
1. 解壓縮此 ZIP。
2. 在瀏覽器開啟 https://app.netlify.com/drop
3. 依網站提示登入或註冊。
4. 將解壓縮後的 `passion_cabin_web` 資料夾拖到頁面上（資料夾內要直接看到 `index.html`）。
5. 等待完成，Netlify 會提供一個 `https://...netlify.app` 網址。把網址加入書籤，或在 iPhone Safari 點「分享」→「加入主畫面」。

## 更新網站
修改檔案後，重新把整個資料夾部署到 Netlify 即可。保留好 JSON 備份。
